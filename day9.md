# Day 9 – NutriScope: MVP vs Enhanced

## Project Overview
Built the NutriScope application using Claude AI. First, I created an MVP (Minimum Viable Product) with the core nutrition tracking features. Then, I enhanced the application by improving the UI, usability, and overall user experience.

## MVP vs Enhanced Comparison

| Feature | MVP | Enhanced |
|---------|-----|----------|
| User Interface | Basic and functional | Modern and polished |
| Design | Simple layout | Improved colours, spacing, and typography |
| Features | Core nutrition tracking | Enhanced functionality and refinements |
| User Experience | Easy to use | More interactive and intuitive |
| Data Display | Basic nutrition information | Better organized and more informative |
| Responsiveness | Basic | Improved responsiveness |
| Overall | Functional prototype | More polished and user-friendly application |

## Key Learnings
- Understood the difference between an MVP and an enhanced application.
- Learned how prompt engineering improves application quality.
- Built and refined a complete HTML application using Claude AI.
- Improved the application's design and user experience through iterative prompting.
